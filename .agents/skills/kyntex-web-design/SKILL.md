# Kyntex website design

Read the shared design reference at https://github.com/Kyntex-org/.github/blob/main/DESIGN_PHILOSOPHY.md. The locally retained reference is docs/DESIGN_PHILOSOPHY.md. Its color roles, logo rules, and principles supersede previous exploration notes.

The approved accent is muted jade #91B5A6, on black, white, and neutral charcoal. Use dark text on jade fills. Do not restore the previous navy/blue, peach, or purple exploration.

The main site introduces the band and its value to athletes. Engineering lives at /engineering/. Demo requests go to kyntexsupport@gmail.com; the intended domain is kyntex.org. Retail sales await actual launch details.

Use actual Kyntex photography and the current monochrome logo. Product references explain form only. Keep prototype and sample states honest. Never invent testimonials, measurements, prices, medical benefits, or availability.

Use restrained motion and respect reduced motion. Verify keyboard focus, accessible names and units, contrast, mobile layouts, and the production build. Do not present photography placeholders as a finished launch.
